# Word Hunt Windows Edition

A modern, offline-first Word Search Adventure game engineered for Windows and desktop browsers.

## 🔒 Privacy, Security & Copyright
- **100% Offline & Private**: Zero external API keys or remote server connections.
- **Copyright**: © 2026 Word Hunt Windows. All Rights Reserved. Created & Owned by Developer.
- **Anti-Theft Protection**: Built-in anti-inspection and tamper-shield to protect proprietary game logic.

## 🚀 Run Locally
1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Run the development server:
   ```bash
   pnpm run dev
   ```
3. Build for production (minified, protected, zero sourcemaps):
   ```bash
   pnpm run build
   ```
